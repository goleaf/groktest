# Internationalization

Borrowed ships one self-contained locale definition per language:

- `src/app/i18n/en.ts`
- `src/app/i18n/ru.ts`
- `src/app/i18n/lt.ts`

Each file owns its language code, `Intl` locale, HTML language, flag, native display name and complete message tree. Components never import a language file directly. They use `I18n.t(key, params)` and `I18n.locale()`.

## Runtime

`catalog.ts` is the only registry. It assembles locale files, derives the `SupportedLanguage` TypeScript union and provides metadata for the language switcher. `I18n` resolves a message from the active locale, falls back to English, interpolates named parameters and updates `<html lang>`.

The chosen language is stored in `LocalSettings.preferredLanguage`. Dexie schema v3 adds `en` to existing installations without deleting records. Switching language writes the setting and its future sync mutation in one local transaction.

Counts use locale definitions rather than concatenated sentence fragments:

```ts
openCount: plural({
  one: '{count} open record',
  other: '{count} open records',
});
```

`Intl.PluralRules` selects `one`, `few`, `many` or `other` for the active locale. Every plural definition must include `other`.

## Adding a language

1. Copy `src/app/i18n/en.ts` to a new language file.
2. Translate every message and set that file's `code`, `locale`, `htmlLang`, `flag` and native `name`.
3. Add its locale export to `localeCatalog` in `src/app/i18n/catalog.ts`.
4. Run `pnpm test`, `pnpm lint`, `pnpm typecheck` and `pnpm build`.

No component, persistence union or language-switcher option needs manual editing. `SupportedLanguage` and selector options are derived from the registry.

## Integrity contract

The i18n test suite rejects:

- missing or unexpected message keys;
- different interpolation parameters between languages;
- plural/non-plural shape mismatches;
- mismatched registry and locale-file codes.

User-visible text, accessible labels, placeholders and errors belong in locale files. Proper names and user-entered content are not translated. Translated sentences must remain whole; do not concatenate fragments whose grammar changes by language.
